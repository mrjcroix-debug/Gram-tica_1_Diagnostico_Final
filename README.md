# Simulado de Gramática — ETEC

Página pública para os alunos praticarem o simulado. Ao finalizar, as respostas e os dados de identificação são encaminhados ao Google Forms vinculado; os resultados devem ser consultados na planilha de respostas desse formulário.

O painel do professor não está incluído nesta versão pública. A publicação é feita pelo GitHub Pages por meio do workflow em `.github/workflows/pages.yml`.
